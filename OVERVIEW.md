Agent tree shows, live, everything a Claude Code agent runs under it: Workflow runs with their phases and agents, Agent tool subagents, background shell commands, background agents and the todo list. It is a compact sidebar in the style of Claude Code's desktop app: under a Main row, one "Background tasks" list of workflows, subagents and background tasks, and a "Progress" section for the todo list. Each row's first line holds an icon for what it is (agent or shell), its title and, on the right, its live time while it runs, its duration once it completed, or Failed, Stopped or Queued. Under it, a running agent says what it is doing now; a finished one shows its model (when it differs from the session's) and its tokens; a shell shows only what its notification adds, such as "exit 1" or "time limit". Sections fold, and finished rows fold under "{n} finished" while something runs. Pressing an agent row shows its last tool calls in place; View transcript opens the agent's prompt, its full step list with each tool call's input and result, its tokens (input, output, cache read, cache write and the context of its latest call) and its final answer.

It opens in the Explorer, the right sidebar, from the Command Center, the `/agent-tree` slash command or the Agents pill in the composer, which counts the agents running under that agent. It can also be opened as a workspace tab, where the same rows get wider. The Agent runs screen, in the sidebar or from Open agent runs in the Command Center, lists the Claude Code sessions active in the last 24 hours (the 40 most recent) with their running agents, workflows, tasks and token totals.

The plugin's server reads local files on the daemon's machine and writes none: the Paseo agent records in `$PASEO_HOME/agents` (default `~/.paseo`), and the Claude Code transcripts, subagent and workflow files in `$CLAUDE_CONFIG_DIR` when set, plus `~/.claude` and `~/.config/claude`. It starts no process, makes no network call and calls no model. It reads only the bytes added since its last read, so the panel can refresh every 2 seconds while something runs and every 15 seconds otherwise. Polling and the live clocks stop while the app is in the background and while the panel is hidden, such as when another Explorer tab or another workspace is in front.

Statuses follow Claude Code's own records: a workflow journal result or failure, a tool result, a task notification or a TaskStop. Without one, an agent or task that wrote nothing for 30 minutes is shown as Stopped. An agent waiting on a subagent counts as active while that subagent is, and a background shell counts as running while the agent that started it runs. When a workflow agent is retried or a run is resumed, the row shows the latest attempt, and its counters include the earlier attempts.

Text from transcripts is cleaned before it reaches the app. Card, IBAN, Emirates ID, passport and account numbers are masked, as are API keys, tokens, passwords and other secret-looking values, and your home directory is shortened to `~`.

It reads Claude Code sessions only. Agents on other providers show a short notice instead of a tree. It needs Paseo 0.14.0 or newer on the daemon and on each connected app, and it was checked against the file formats of Claude Code 2.1.299 to 2.1.308.
